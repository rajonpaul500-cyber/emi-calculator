What is percent error?

Percent error compares a measured or observed value with a true or accepted value. The formula is |observed - true| / true × 100. It tells you how large the mistake is relative to the correct value.

Because of the absolute value, percent error is always zero or positive. It measures the size of the error, not its direction. A result close to 0% means the measurement was very accurate.

When is percent error used?

Students use it in chemistry and physics experiments to compare experimental results with textbook values. Surveyors and engineers use it to check how well a measurement or prediction matches reality.

A related but different measure is percent difference, which compares two measured values using their average as the base. This calculator focuses on the observed-vs-true comparison, the most common form.

Pro tips

  • Use the true value as the accepted/reference value, not your measurement.
  • A negative signed error means the observation was below the true value.
  • For comparing two measurements, consider percent difference instead.

Frequently asked questions

What is the percent error formula?▶
Percent error = |observed - true| / true × 100. The absolute value keeps the result positive regardless of direction.
Why is percent error always positive?▶
Percent error uses absolute value because it measures the magnitude of the error. If you need direction, use the signed error shown alongside.
What is a good percent error?▶
In many school experiments, errors under 5% are considered acceptable, but the threshold depends on the field and the precision of the equipment.
What is the difference between absolute and percent error?▶
Absolute error is the raw difference between observed and true values. Percent error divides that difference by the true value and multiplies by 100, putting it on a comparable scale.
Can percent error be used for negative values?▶
Yes, but the true value must not be zero. The calculator handles negative numbers correctly using absolute values.
